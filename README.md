# 🎮 2048 Game | Python & Tkinter

A classic **2048 puzzle game** built using Python and Tkinter. Merge tiles with the same number, increase your score, and challenge yourself to reach the 2048 tile!

## ✨ Features

- 🎯 Interactive 4×4 game board
- ⌨️ Keyboard controls using arrow keys
- 🔢 Automatic tile merging
- 🏆 Real-time score tracking
- 🎨 Colorful game interface
- 🔄 New Game button to restart
- 🛑 Game-over detection

## 🛠️ Technologies Used

- **Language:** Python 3
- **GUI Framework:** Tkinter
- **Module:** Random

## 📸 Game Preview

The game features a 4×4 grid where matching numbered tiles merge when moved in the same direction.

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your system
- Tkinter available in your Python installation

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/2048-game.git
```

**2. Navigate to the project folder**

```bash
cd 2048-game
```

**3. Run the game**

```bash
python game2048.py
```

## 🎮 How to Play

1. Use the **↑ Up, ↓ Down, ← Left, → Right** arrow keys to move the tiles.
2. Tiles with the same number merge into one tile with double the value.
3. Earn points by merging matching tiles.
4. Try to create the **2048 tile**!
5. When no more moves are possible, the game ends.
6. Click **New Game** to start again.
